# 视频格式转换器

使用 Python、PySide6 和 FFmpeg 开发的 Windows 桌面视频转换工具。

支持选择视频、显示视频信息和缩略图、转换为 MP4/MKV、质量预设、
真实进度显示以及取消转换。

## 功能

- 选择本地视频并显示路径。
- 显示视频编码、分辨率、时长和文件大小。
- 提取并显示视频第一帧作为缩略图。
- 支持 MP4、MKV 输出。
- 提供高质量、均衡、较小体积三档预设。
- 使用 H.264 视频编码；存在音轨时转换为 AAC。
- 根据 FFmpeg 输出的处理时间计算进度。
- 支持取消转换，取消后可以重新开始。
- 拒绝覆盖源视频和已有输出文件。
- 转换失败或取消时清理本次临时文件。

## 运行环境

- Windows
- Python 3.12
- PySide6，具体安装版本见 requirements.txt
- FFmpeg 和 ffprobe 命令行工具

当前仅在本机 Windows 环境验证，其他电脑尚未验证。

## 安装与启动

### 1. 创建 Python 环境

在项目目录执行：

```powershell
py -3.12 -m venv .venv
```

### 2. 安装 Python 依赖

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### 3. 准备 FFmpeg

从 FFmpeg 官方下载页进入 Windows 构建下载入口：

https://ffmpeg.org/download.html

将完整的 Windows FFmpeg 包放入 tools/ffmpeg，
保留 LICENSE、README.txt 等文件，并确认存在：

```text
tools/ffmpeg/bin/ffmpeg.exe
tools/ffmpeg/bin/ffprobe.exe
```

FFmpeg 工具文件不随源码仓库上传，需要另行准备。

### 4. 使用 PyCharm 启动

1. 使用 PyCharm 打开项目文件夹。
2. 将 Python 解释器设置为项目中的 `.venv\Scripts\python.exe`。
3. 将运行配置的脚本设置为 `main.py`，工作目录设置为项目根目录，脚本参数留空。
4. 在项目列表中右键 `main.py`，选择“运行”；之后也可以选择对应运行配置，点击右上角绿色运行按钮启动。

## 使用方法

1. 点击“选择视频”。
2. 检查视频信息和缩略图。
3. 选择输出格式与质量预设。
4. 设置输出文件完整路径。
5. 点击“开始转换”，等待完成。
6. 在资源管理器中打开成品，观看画面并试听声音。

转换期间可以点击“取消转换”。
等待取消完成、控件恢复后，可以重新开始。

输出文件的扩展名需要与所选格式一致。
例如选择 MKV 时，输出路径应以 .mkv 结尾。

## 工程决策

### 桌面界面

选择 PySide6，满足客户端要求，并使用自己熟悉的 Python 开发。

### 后台任务

使用 QThread 执行信息读取、缩略图提取和转换。
后台通过信号传递结果，由主线程更新界面，避免阻塞窗口。

### 视频流选择

根据 codec_type 查找视频画面流，排除附带封面。
实测素材的第一条流是音频，因此不能直接把 streams[0] 当作视频。

### 真实进度

读取 FFmpeg 的 out_time_us，将微秒转换为秒，再除以输入总时长。

实测发现进度曾从 92% 回退到 90%，因此保留历史最大值，
并过滤重复通知，使显示单调递增。

正式输出完成验证和保存后才报告 100%。
无法获取有效时长时，界面显示活动进度，不虚构百分比。

### 取消转换

使用 threading.Event 传递取消请求。
监控线程负责停止 FFmpeg，转换函数随后清理临时文件。

如果取消请求发生在探测或验证阶段，
可能需要等待当前 ffprobe 操作结束后才能返回取消结果。

### 输出保护

先检查源路径、输出路径、输出目录和已有文件。
转码写入程序独占的临时文件，验证后再保存为正式输出。

FFmpeg 的覆盖参数只作用于本次临时文件。
Windows 下正式发布使用不覆盖已有目标的重命名操作。

### 缩略图故障隔离

缩略图提取失败时，保留已经成功读取的视频信息，
允许用户继续尝试转换。

## AI 协作会话总结

本项目使用 AI 辅助开发，按照步骤编写、运行并进行测试。

1. 创建独立 Python 环境，完成桌面窗口。
2. 添加文件选择，验证路径更新和取消选择。
3. 在终端验证 ffprobe，再编写信息读取模块。
4. 通过后台线程把视频信息接入窗口。
5. 提取 PNG 缩略图，再接入窗口预览。
6. 单独测试转换设置组件，并接入主窗口。
7. 在命令行验证转换，再封装转换函数。
8. 添加窗口转换按钮，验证错误提示和输出保护。
9. 读取 FFmpeg 进度，发现并修正进度回退。
10. 添加取消标记、进程停止和窗口取消按钮。
11. 验证取消后重试、无音轨输入，并整理说明文档。

开发中的反馈包括：
文件创建位置错误、进度回退，以及测试时输出格式与扩展名不一致。
根据实际报错和截图逐项定位，再重新验证。

## 已知限制

- 一次只处理一个转换任务。
- 只输出 MP4 和 MKV。
- 选择第一个视频画面流和第一音轨。
- 不保留字幕、章节和其他音轨。
- 不提供 HDR 色彩管理、硬件加速或视频剪辑。
- 质量预设为有损转码，不保证输出文件一定更小。
- 输出可读性检查不等于对成品逐帧验证。
- 尚未验证所有编码、超大文件和其他电脑环境。
