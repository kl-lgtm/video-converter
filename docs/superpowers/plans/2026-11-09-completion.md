# 视频转换器完成计划

> 实现方式：本会话直接完成。采用 writing-plans、executing-plans 和 test-driven-development 技能。

## 已批准设计
Windows / Python 3.12 / PySide6 / FFmpeg 命令行；单文件导入、信息、缩略图、MP4/MKV 转换、质量预设、真实进度、取消、打开输出目录。保留原探测模块，增加后台任务与转换服务。开发记录必须区分用户反馈、AI 决策和实际验证。

## 边界与决策
- 不覆盖源文件或已有输出；转换使用同目录独占临时文件，成功探测后发布。
- 第一视频画面流、第一音轨；不保留字幕、章节、多音轨或 HDR 特性，不声称无损。
- 不将私人视频、绝对私人路径、虚拟环境、FFmpeg 二进制上传 GitHub；提供下载说明。
- 发布到 GitHub 前检查身份与仓库能力，不能发布时提供可提交源码包与明确步骤。

## 验收重点
转码失败不留下正式成品；无音轨可转换；未知时长不假造百分比；取消不伤原文件；关闭不遗留进程；缩略图失败可继续转换；不存在或无写权限的目录有提示。
