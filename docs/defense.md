# 答辩准备：用自己的话解释项目

请实际打开软件并操作一遍，再回答下面的问题。不要把 AI 自动验证说成本人手测。

1. **为什么选 PySide6？** 题目要求客户端，自己熟悉 Python；Qt 提供桌面控件、布局、线程与进程管理。
2. **FFmpeg 与 ffprobe 的区别？** 一个转码和截图，一个探测流与容器信息。通过参数列表调用外部程序，不是集成 C API。
3. **MP4 与 H.264 的区别？** MP4 是容器，H.264 是视频编码；本项目输出不只是改后缀。
4. **为什么不在按钮方法直接 subprocess.run？** 它等待外部进程，可能阻塞界面。探测放后台，转换用异步 QProcess。
5. **怎么得到进度？** 读取 `-progress pipe:1` 的 out_time_us，除以输入时长；它是估算。退出成功和输出可读后才显示 100%。
6. **如何防止覆盖？** 先校验源与目标，再创建同目录独占临时文件，最终发布也不能覆盖已存在目标；这样可以处理转换期间其他人创建同名文件的竞争。
7. **取消怎么实现？** 请求进程终止，必要时延时强制结束；收到结束事件后删除自己创建的临时文件，恢复控件。
8. **如何处理无音轨？** 映射参数使用可选音轨 `0:a:0?`，没有音轨时只输出视频。
9. **AI 哪些地方需要你判断？** 界面选型、三天范围、错误是否可恢复、测试是否真的运行、源文件保护是否充分。会话里本人确认了方案并提供环境报错和验收反馈，后期交由 AI 实现。
10. **已知限制是什么？** 单任务、软件编码、第一视频和第一音轨；不保留字幕、多音轨和 HDR，质量预设有损，输出未必更小。

建议演示顺序：选视频→缩略图与信息→修改格式/预设→转换→打开目录；另演示误选文件后恢复、取消后重试。现场说明边界，不声称支持未经验证的功能。
