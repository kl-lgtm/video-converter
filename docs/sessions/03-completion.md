## AI 提议并实施的工程决策
- 保留视频探测模块，新增 media.py 集中管理工具路径、参数、临时文件和进度。
- 信息和缩略图通过 QThread 后台执行；转码通过 QProcess 异步执行。后台不直接操作界面。
- MP4/MKV 采用 H.264 + 可选 AAC 音轨；用三档 CRF 降低用户配置成本。
- 第一视频画面流与第一音轨，明确不承诺保留多音轨、字幕、HDR 等信息。
- 仅对本次独占临时文件使用覆盖参数；输出验证后再以不覆盖目标的方式发布。避免失败成品与同名覆盖。
- 取消后先结束进程再清理临时文件；运行中阻止关闭。未知时长不假造百分比。
- 优化选择拖拽、预设、同名自动编号、完成后打开目录，不扩大到剪辑或批量功能。
- 生成测试素材用于公开文档截图；不把用户私人视频纳入交付。

## 验证与反馈闭环
- 新增转换服务前，先运行边界测试，观察缺少模块导致失败；实现后通过。
- 真实 FFmpeg + Qt 事件循环测试验证 MP4/MKV、无音轨、缩略图、取消后重试、非法文件恢复、输出保护、缺失工具、进程启动失败及界面事件循环仍在运行。
- 无界面测试环境的截图缺少中文系统字体，因此改用 Windows 平台实际渲染检查；该现象没有被误判为产品字体故障。
